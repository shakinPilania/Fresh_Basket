# FreshBasket 🥬

FreshBasket is a simple and responsive **online vegetable-selling e-commerce website** built using **React.js and Tailwind CSS**. It provides a user-friendly shopping experience where users can browse vegetables, add products to their basket, manage quantities, apply coupons, and place orders.

## Features

* Browse available vegetables
* Add vegetables to the basket 
* Like products and automatically add them to the wishlist
* Increase or decrease product quantity
* Remove products from the basket
* Dynamic subtotal and total price calculation
* Apply coupon codes
* Delivery charge calculation
* Responsive design for different screen sizes
* Client-side navigation using React Router
* State management using React Context API

## Technologies Used

* React.js
* JavaScript (ES6+)
* Tailwind CSS
* React Router
* React Context API
* HTML5
* CSS3

## React Concepts Used

This project helped me practice and understand several important React concepts:

* **useState** – Managing component state and user interactions
* **useEffect** – Handling side effects and data operations
* **Context API** – Sharing application state across components
* **React Router** – Navigating between different pages without reloading
* **Component-based architecture** – Building the application using reusable components
* **Props** – Passing data between components
* **Event handling** – Handling clicks, inputs, and other user interactions
* **Array methods** – Using `map()`, `filter()`, and `reduce()` for dynamic data handling
